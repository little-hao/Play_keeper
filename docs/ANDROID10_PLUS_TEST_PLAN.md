# Play Keeper Android 10+ 回归测试

## 系统矩阵

- Android 10、12、14、15 及以上可获得的真机或模拟器。
- Android System WebView/Chrome 保持系统可用的最新稳定版。
- 至少覆盖一台屏幕有挖孔/刘海和底部手势区的设备。

## 安装与升级

1. 从 v1.3.0 直接覆盖安装 v1.4.0，确认4个 WebView Profile 的登录状态保留。
2. 核对应用名为 Play Keeper，图标为已确认的候选 B。
3. 检查横竖屏、状态栏/手势区、黑屏遮罩和渲染进程恢复。

## 脚本回归

1. 人为停在“请将手机横屏使用”页，确认脚本只点击一次“手机转不动？点这里继续”；如页面仍未恢复，脚本应报错且不再点击。
2. 卖方配置10件装备，确认一键脱装、前5件上架、等待成交、后5件上架的顺序。
3. 买方脚本应等待缺失装备，不得直接跳过；同名同价多条时应中止。
4. 全部购买后检查“宠物资料 → 一键穿装备 → 挂机辅助 → 绘画小屋”。
5. 绘画小屋必须先出现“停止挂机”，随后退出该状态，才能记录为副本完成。
6. 分别选择三组拍卖预设，检查 Android 和远程端的自定义文本是否同步。

## 远程页面

- iPhone Safari 竖屏和桌面浏览器均要检查：基础按钮在上，手机画面在中，一键脚本在下。
- 720/1280/2560 三档预览继续保持等比 `contain`，横竖屏都不应裁切。
- 30分钟战斗统计不增加时，对应账号页签应标记掉线。
