# Play Keeper 2.0.5-rc1 验收重点

1. 在 VPS 为 hao7 选择“情人套装”，卖方 hao7、买方 hao，先观察装备交易所加载。
2. 页面暂未读取到目标装备时，应显示刷新重试次数，不得立即跳过下一件。
3. 五次重试仍未识别时，脚本必须停止，并显示页面实际读取到的装备名称。
4. 成功识别后，验证两批各最多五件的上架、购买和穿戴流程。
5. 在账号高级设置中把“副本技能”设为 `auto`，进入副本时应选择第二个攻击/伤害技能。
6. 将技能改为页面中的具体名称，保存后再次运行，确认按该账号配置选择。
7. 技能不存在时应安全回退到自动规则，并在运行状态中显示实际选中的技能。
