# Play Keeper v2.0.6 正式版说明

发布日期：2026-11-02

## 本版内容

- 副本组合可配置攻击技能，并可选择在全部副本结束后自动处理“已接受的任务”中当前可完成的任务。
- 新增野外自动捕捉。地图默认圣诞小屋，每次进入地图只开启一次自动攻击，每场战斗触发一次捕捉；有可用精灵球时立即使用，无球时继续运行。
- 新增通天塔自动战斗入口：进入第二张野外地图、选择第一排第二个伤害技能并开启自动攻击。
- Android 本地设置与 VPS 控制台同步提供任务开关、地图配置和单独启动入口。

## 验证结论

- 真实页面已验证可完成任务的“选择 → 完成 → 刷新”流程，完成后的任务不会继续出现在已接受任务列表。
- 圣诞小屋入口、自动攻击、逐场捕捉、无精灵球分支、继续探险恢复和通天塔二级地图入口均已验证。
- Android 单元测试、Candidate/Release 构建检查与 VPS 65 项协议测试全部通过。
