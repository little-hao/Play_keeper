# Play Keeper v2.0.4 正式版说明

发布日期：2026-10-25

## 本版内容

- 正式合入 v2.0.4-rc1/rc2 的真机验收结果：不同用户可在不重叠设备并行运行；设备短暂离线可在原装备交接段续跑；自定义路线在买方完成后不再被上一卖方收尾阻塞。
- 最终主号按控制台保存的道具价格购买，无论购买成功、失败或超时，都会回到该账号配置的指定副本挂机。
- 远程控制台顶部明确显示登录用户、当前脚本、开始时间和实时运行时长，并针对电脑、平板和手机浏览器优化密度、间距和换行。
- APP 自动化遥测增加脚本开始时间，远程运行时长以真实启动时间计算。

## VPS 升级

VPS 服务版本为 `2.0.4`。替换程序前必须备份并在升级后保留：`.env`、`remote-server/data/users.json`、计划状态、单次转移状态、诊断与截图目录、邮件配置。不要使用发布包覆盖这些生产数据。
