# Play Keeper v2.0.4-rc3 候选版说明

构建日期：2026-10-28。Android 候选包使用独立应用 ID
`com.local.sgplaykeeper.candidate`，versionName `2.0.4-rc3`，versionCode `53`；
VPS 健康版本为 `2.0.4-rc3`。

## 三层改动

1. **RC1 底座**：VPS 为每条计划命令分配稳定 `stepId`；APP 在执行前持久登记，结果写回本地账本。VPS 同时记录步骤和状态事件。设备掉线默认等待120秒，在宽限期内不判定交易失败。
2. **RC2 恢复**：同一 `stepId` 的重发只回放本机结果。遥测带连接会话与单调序号，VPS 用 APP 执行账本对账丢失确认；VPS 重启后恢复未确认步骤。卖方、买方/副本、道具阶段分别支持30–3600秒超时。
3. **RC3 诊断**：卡顿或宽限期耗尽时生成 JSON 诊断包。在线设备会提供当前账号截图；VPS 可选调用 OpenAI Responses API，把截图和脱敏事件/步骤日志转成结构化诊断建议。

## 安全边界

- GPT 输出只保存在诊断包并显示于“等待人工处理”区域，没有自动调用 APP 命令的代码路径。
- `OPENAI_API_KEY` 只允许配置在测试 VPS 环境变量；不进入 APK、浏览器消息、诊断包或 Git。
- APP 进程若在步骤执行中被系统杀死，会把未决本地步骤标记为“结果不明”，要求 VPS/人工对账，不假定成功，也不盲目重复交易。
- 超时只停止计划并保留现场；不会自动撤单、覆盖在售商品或确认装备所在账号。

## 部署边界

该版本是候选测试版本，不自动替换生产 v2.0.3。先更新测试 VPS，再覆盖安装独立候选 APP。正式 APP 与候选 APP 的远程设置、WebView 会话和本地账本相互隔离。
