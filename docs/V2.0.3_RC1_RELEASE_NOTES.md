# Play Keeper v2.0.3-rc1 候选版说明

发布日期：2026-10-22
状态：候选版，未部署生产

## 本轮目标

本版针对 v2.0.2 真机测试中发现的三个问题：

1. 买方完成装备穿戴、副本和回圣殿后，VPS 可能仍停留在上一段，无法自动进入下一次装备转移。
2. 人工确认套装所在账号时，因当前运行路线已被裁剪，`hao5`、`hao6`、`hao7` 等后续账号不再显示。
3. 再次启动多用户挂机时，已经在当天完成副本的账号仍被重复纳入装备接力。

## 行为变化

- 系统同时保存“完整配置路线”和“本轮有效路线”。配置路线不会因跳过或恢复而丢失账号。
- 启动和人工恢复时，自动排除北京时间当天已完成副本的后续账号。
- 当前装备持有者始终保留在有效路线起点，主号始终保留在路线终点，确保套装最终返回主号。
- 示例：完整路线为 `hao → hao1 → hao2 → hao3 → hao4 → hao5 → hao6 → hao7 → hao`，若 `hao1` 至 `hao5` 已完成副本，本轮实际执行 `hao → hao6 → hao7 → hao`。
- 人工确认账号列表合并完整路线、有效路线和当前用户账号设置；在线账号均可选择，离线账号保留显示并标注离线。
- 手机回执时间不再直接与 VPS 绝对时间比较，而是与该账号启动前自身记录比较，降低设备时钟偏差造成的误判。
- 控制台直接显示本轮有效路线及被跳过账号，配置输入框继续保留用户原始闭环路线。

## 真机验收重点

本版仍需用户按 `docs/V2.0.3_RC1_ACCEPTANCE.md` 完成真机闭环，尤其确认：

- `hao → hao6 → hao7 → hao` 是否自动完成装备转移、副本、剩余装备穿戴、背包刷新和回圣殿。
- `hao6`、`hao7` 完成后，主号 `hao` 是否执行道具购买并最终回到圣殿。
- 中断后人工确认下拉框是否包含完整八账号，选择实际套装账号后是否仅继续剩余未完成路线。
