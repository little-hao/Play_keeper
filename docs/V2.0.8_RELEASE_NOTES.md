# Play Keeper 2.0.8 正式版说明

发布日期：2026-11-28

## 本次更新

- 以 `v2.0.8-rc2` 为基线，合入日常任务稳定探测和副本启动双证据修复，降低页面延迟造成的误报。
- 工具栏支持收起；收起后在状态栏安全区域内保留“展开工具”按钮，横屏、竖屏和异形屏均可恢复操作区。
- 单台 Android 设备可配置 4–16 个独立实例。每个实例分别保存 WebView Profile、登录状态、名称、首页地址和 HTTP 授权。
- 新增省电、均衡、高性能、16 实例四种配置环境，分别同时驻留 2、4、8、16 个网页；网页渲染进程连续异常时自动回退均衡环境。
- VPS 的用户账号列表、远程命令、预览画面、网页选择、每日任务和装备接力路线均扩展到最多 16 个账号。
- 自定义实例默认只允许 HTTPS；如确需 HTTP，必须对该实例显式开启，运行时仍仅允许游戏旧域名或该实例配置的同源地址。

## 升级说明

- 正式 APK 包名仍为 `com.local.sgplaykeeper.test.v190`，使用既有正式签名，可直接覆盖安装并保留原 4–8 个账号的 Profile 与设置。
- 正式版 `versionCode` 为 `2000810`、`versionName` 为 `2.0.8`，高于 `v2.0.8-rc2`。
- 初次升级仍使用“均衡”环境并保留旧性能设置的兼容迁移；要启用 9–16 个账号，请在 APP 的“实例”中配置数量与环境。
- 16 实例环境会显著增加内存、温度和耗电，建议先在“均衡”或“高性能”环境验证设备稳定性。
- VPS 替换程序文件前必须备份并保留 `.env`、`data/`、用户与设备归属、计划状态、邮件配置和诊断记录。
- 升级后 `/health` 应返回 `2.0.8`，浏览器建议强制刷新一次以加载新版控制台资源。

## 验证结果

- Android Release 单元测试、Lint 与正式构建通过。
- VPS 75 项自动测试全部通过，另补充 16 账号边界与索引 15 路线测试。
- APK 包名、版本号和签名证书在生成制品后再次核验。

## 安全说明

- Release 不包含签名密钥、`.env`、用户凭据、Cookie 或生产 `data/`。
- 多实例只隔离 APP 内的 Profile 和配置，不伪造设备身份，也不绕过网站针对 IP、设备或账号的限制。
