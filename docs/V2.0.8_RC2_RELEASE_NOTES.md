# Play Keeper v2.0.8-rc2

## 本版重点

- 合并 v2.0.8-rc1.1 的 8 账号并发调度与高性能模式。
- 修复“一键日常任务”在副本结束后无法继续领取可完成任务的问题。
- 可完成任务只识别当前可见列表中带绿色状态点的任务，避免把普通已接受任务误判为可领取。
- 扩展任务弹窗、标签和确认按钮识别，完成后再次扫描验证。
- 一键接受和领取可完成任务超过 30 秒时记录警告并继续下一阶段，不再中止整体流程。
- 保留“领取完成任务奖励”单独测试入口。
- 保留最多 12 件装备（10 个穿戴槽位 + 2 个卡片槽位）的定向转移。
- 优化远程控制台的每日任务状态展示和移动端布局。

## 测试建议

1. 先对单个账号执行“领取完成任务奖励”，确认仅处理绿色状态点任务。
2. 运行完整日常流程，确认“接受任务 → 副本 → 领取可完成任务 → 后续阶段”可连续执行。
3. 分别在普通模式和高性能模式下运行 8 账号，核对超时账号是否记录警告并继续。

## 安装与部署

- APK 为主版覆盖安装包，保持原包名和签名。
- VPS 包解压后按现有部署流程替换程序文件；不覆盖 `.env`、`data/users.json`、计划状态和邮件配置。
