# Play Keeper 2.0.7 正式版说明

发布日期：2026-11-07

## 本次更新

- 新增各账号并行每日任务，支持每账号副本、技能、返回挂机地图、背包汇总、可选拍卖与邮件报告。
- 新增独立“领取完成任务奖励”按钮，无需跑完整流程即可验证任务页和奖励领取。
- 任务奖励只识别任务条目前的绿色圆点；一键接受与奖励领取约30秒超时后记录警告并继续后续阶段。
- 装备定向转移扩展为12件，对应10个目标穿戴槽和2个卡片槽，交易仍按 `5 + 5 + 2` 分批完成。
- 优化远程控制台每日任务状态卡片，在电脑与手机端分别采用三栏和自动折行布局。

## 升级说明

- 正式 APK 保持 `com.local.sgplaykeeper.test.v190` 包名与原签名，可覆盖升级现有正式版。
- VPS 替换程序文件前请备份并保留 `.env`、`data/`、用户与设备归属、计划状态、邮件和诊断数据。
- 升级后 `/health` 应返回 `2.0.7`，浏览器建议强制刷新一次以加载新版控制台资源。

## 验证结果

- Android Release 单元测试、Lint、构建与签名验证通过。
- VPS 71项自动测试全部通过。
- 候选版 `2.0.7-rc4` 已完成用户真机测试后转为本正式版。
