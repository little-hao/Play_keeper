# 多用户挂机报错说明

从 v2.0.2-rc4 开始，VPS 会按远程控制台登录用户独立保留“多用户挂机”运行报错，避免不同用户、不同设备的记录混在一起。

## 如何取得文档

登录远程控制台，在“挂机脚本”区域点击“下载本用户报错说明”。下载文件名包含当前用户名；没有报错时，文档会明确显示尚无记录。

## 自动记录内容

- 北京时间与运行编号
- 当前状态、流程阶段和完整装备循环
- 当前装备转移段
- 报错账号
- 装备所在账号
- APP/VPS 返回的完整错误说明

同一个错误状态只记录一次。用户人工恢复后出现的新错误会追加在原文档末尾，方便开发者比较前后运行结果。

## VPS 留存位置

文档默认位于用户数据文件同级的 `diagnostics/` 目录。生产服务使用示例配置时，对应 `/var/lib/play-keeper/diagnostics/`。更新 APK、替换 VPS 程序目录或重启服务不会删除这里的历史记录。

请不要手工把其他用户的文档复制到当前用户的数据目录；如需提交给开发者，直接下载当前用户文档并附上问题发生时的页面截图即可。
