## 12件装备转移

1. 在网页端配置12件不重复项目，包含10件常规装备与2张卡片。
2. 卖方应自动以 `5 + 5 + 2` 三批上架，不应在第10件后提前完成。
3. 买方成交后自动穿戴；最终核验应显示10个装备槽和卡片1/卡片2都有目标项目。
4. 任何一件未成交、被跳过或未穿戴时，不得将该棒标记完成。
5. 再回归10件旧套装，确认两个卡片槽不会阻塞旧流程。

## 一键完成任务

1. 运行每日任务，确认“一键接受日常任务”正常。
2. 副本结束后，在“已接受的任务”中准备至少一项可完成任务。
3. 脚本应选中当前可见任务、点击完成/领取，若出现确认弹窗则自动点击“确定”或“确认”。
4. 确认不再因隐藏弹窗被选中而连续等待；失败时页面显示具体识别阶段。
