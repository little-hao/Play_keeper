# Play Keeper 2.0.7-rc4 候选版验收

## 更新边界

- Candidate 包名为 `com.local.sgplaykeeper.candidate`，可与正式版并行安装。
- 测试 VPS `/health` 必须返回 `2.0.7-rc4`。
- 更新 VPS 时保留 `.env`、`data/`、用户与设备归属、计划状态、邮件和诊断数据。

## 独立领取完成任务奖励

1. 在一个测试账号中准备至少一个已完成、任务名前带绿色圆点的已接受任务。
2. 在该账号“当前账号高级操作 → 挂机守护与存仓”点击“领取完成任务奖励”。
3. 脚本应自行打开挂机辅助任务页、切换到已接受任务，且只点击带绿色圆点的任务。
4. 若出现“完成/领取”和“确定/确认”弹窗，应依次自动处理。
5. 本操作不得启动副本、装备转移、背包存仓或完整每日任务。
6. 页面加载或按钮响应超过约30秒时，应结束本次测试并显示超时警告，不得让脚本保持卡死状态。

## 完整每日任务回归

1. 一键接受日常任务成功时继续副本；30秒内无法确认时记录警告并进入下一阶段。
2. 副本结束后的奖励领取遵循相同的绿色圆点规则；30秒超时后继续背包汇总/返回挂机。
3. 控制台的账号状态、状态徽标和详细信息在电脑端为三栏，在手机端自动折行。
4. 12件装备转移继续按 `5 + 5 + 2` 批次回归，确认本版没有引入退化。
