# Play Keeper v2.0.4-rc1 候选版说明

构建日期：2026-10-25。

## 修复内容

1. 不同用户使用互不重叠设备时，多用户挂机与装备定向转移可以并行；只有实际共用设备时才提示冲突。
2. 接力设备短暂离线后保留当前交接段并等待90秒。设备恢复后从原卖方、原买方继续，迟到的旧命令回执不会污染恢复后的计划。
3. 人工确认套装仍在当前卖方时，恢复原定向转移，不再直接返回圣殿或跳到下一账号。
4. 卖方收尾与副本结束穿戴都会重新识别并点击横屏继续提示；卖方已经不持有套装时，其收尾异常不会阻塞买方后续阶段。
5. 最终主号使用远程页面保存的道具交易价格（`resourcePrice`）购买。无论购买成功、失败或60秒超时，最后都执行该主号配置的指定副本挂机。
