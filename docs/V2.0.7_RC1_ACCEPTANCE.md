# Play Keeper 2.0.7-rc1 测试版验证说明

## 本版目标

- 原“挂机脚本”保持功能不变并默认折叠。
- 各账号每日任务可并行运行：签到、领取日常任务、指定副本、完成挂机辅助页可完成任务。
- 每个账号完成后返回各自指定副本挂机；账号未填写时使用全局默认值。
- 可选道具拍卖严格在全部账号日常流程结束后串行执行；30 秒无选择按“不拍卖”处理。

## 测试重点

1. 在“各账号每日任务”中选择账号、副本和完成后挂机副本。
2. 启动后确认各账号同时开始，且同账号已有脚本时会被 APP 拒绝而不会覆盖现场。
3. 确认任务弹窗在 `AFK.html#/hang` 的“已接受的任务”页签内逐项点击绿色可完成任务并点击“完成”。
4. 确认每个账号最终显示已返回所配置副本挂机，VPS 状态变为完成。
5. 分别验证 30 秒内选择拍卖、选择不拍卖及不操作三种情况；不操作必须默认不拍卖。
