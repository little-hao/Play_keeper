# v2.0.8 正式版验收清单

- [ ] 覆盖安装后原账号、Cookie、远程配置和脚本设置保留。
- [ ] 工具栏可收起；横屏、竖屏及带刘海/挖孔的设备均可通过“展开工具”恢复。
- [ ] 实例数量可设置为 4–16，账号 1–8 的旧 Profile 不被重建。
- [ ] 省电、均衡、高性能、16 实例环境分别最多驻留 2、4、8、16 个网页。
- [ ] 第 9–16 个账号可在 APP 切换，并可从 VPS 控制、预览和选择网页下拉项。
- [ ] 每个实例可独立设置名称和 HTTPS 首页；未显式授权时 HTTP 地址被拒绝。
- [ ] 16 个账号可保存到用户配置并运行每日任务。
- [ ] 自定义装备接力最多包含 16 个唯一账号，并能闭环回到主号。
- [ ] 一键接受、领取完成任务奖励、副本启动与返回挂机仍保持 rc2 后续修复行为。
- [ ] 连续网页渲染进程异常时，配置环境自动回退到均衡。
- [ ] VPS `/health` 返回 `2.0.8`，电脑和手机控制台能加载新版静态资源。
