# Play Keeper 2.0.6-rc1 验证记录与验收重点

## 已完成的真实页面验证

1. **自动完成任务：通过。** 在已接受任务中选择绿色可完成任务 `[支线]黄金陵的影子`，点击“完成”后刷新列表，该任务已消失，未出现重复提交。
2. **任务列表刷新：通过。** 提交后遇到一次页面短暂的“获取任务列表失败”，重新加载“已接受的任务”后恢复，流程能够继续。
3. **圣诞小屋入口：通过。** 已确认可从“野外探险”按文字定位“圣诞小屋”，再点击“战斗”。
4. **自动攻击入口：通过。** 战斗页可按文字定位“自动攻击”，打开后选择弹层中的“自动攻击（剩余次数）”。每次进入副本只需要启用一次。
5. **逐场捕捉入口：通过。** 每场战斗可点击一次“捕捉”；没有可用精灵球时页面明确返回“没有可用的捕捉球”。出现含“精灵球”的选项时脚本会点击使用，不等待捕捉结算。
6. **继续探险恢复：通过。** 自动攻击尚未启用且处于战斗结算页时，可点击“继续探险”，等待下一场加载后再启用自动攻击。
7. **通天塔导航：通过。** 已确认需先点击第一张世界地图顶部向上箭头进入第二张地图，再定位“通天塔”和“战斗”。为保留账号最后一次挑战次数，本轮未执行完整塔战斗。

## 安装后重点复测

1. 在挂机辅助中勾选“副本结束后自动完成可完成任务”，完成一键副本后确认只处理“已接受的任务”里的绿色可完成项。
2. 自动完成多个任务时，确认每完成一项都会重新读取列表，不会误点未完成任务或其他页签。
3. 自动捕捉默认地图为“圣诞小屋”；每次进入副本只启用一次自动攻击，但每场新战斗都触发一次捕捉。
4. 有精灵球时确认点击使用；无球时记录结果并继续，不应阻塞下一场战斗。
5. 通天塔首次完整测试时，确认攻击设置选择第一排第二个伤害技能，再开启自动攻击并运行至结算。
6. 从 VPS 修改地图、副本技能和“自动完成任务”开关，确认 Android 回传状态与网页配置一致。

## 已知边界

- 游戏页面为异步加载，自动化步骤之间保留等待与恢复轮询；网络慢时允许继续等待，不应重复提交任务。
- 候选 APK 使用独立包名 `com.local.sgplaykeeper.candidate`，可与正式版并存安装。
