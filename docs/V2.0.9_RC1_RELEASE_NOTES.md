# Play Keeper 2.0.9-rc1 界面候选版

发布日期：2026-11-28

## 更新内容

- 修复窄屏下“远程在线”、电量温度等工具按钮文字换行。
- 账号栏与操作栏采用单行圆角按钮、统一间距、描边和渐变选中态。
- 操作按钮在窄屏可横向滑动，横屏根据宽度自动铺开。
- “展开工具”悬浮按钮支持直接拖放，拖动位置会持久保存。
- 横竖屏切换后按比例恢复悬浮位置，并自动避开状态栏、导航栏和屏幕切口。

## 安装说明

- 本 APK 使用正式包名和既有签名，可覆盖安装 v2.0.8 并保留账号登录资料。
- 版本号为 `versionCode 2000901`、`versionName 2.0.9-rc1`。
- 本次仅修改 Android APP 界面，VPS 继续使用 v2.0.8，无需重新部署。
