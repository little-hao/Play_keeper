# Play Keeper v2.0.3-rc2 候选版说明

发布日期：2026-10-23
状态：候选版，未部署生产

## 本轮问题

设备 `PK-C3AB5AFFB4A3` 在 `hao6 → hao7` 装备转移中断网。恢复时部分装备已经成交、部分仍在交易所、部分仍在卖方背包，但旧流程把目标装备数量当作全部交易栏位占用数，并且只重新启动卖方，导致：

- 卖方反复等待或尝试上架已经处理过的装备；
- 买方没有同步恢复，已经上架的装备无人购买；
- 出现“未检测到背包数量变化，请检查五件上架限制”；
- 人工确认从 `hao6` 继续后仍无法跨过部分转移现场。

## 修复内容

- 上架前同时核对三类证据：卖方背包目标装备、交易所中的目标装备、交易所全部有效商品栏位。
- 已经上架或已经成交的装备不再重复上架；仍在背包中的装备在栏位腾出后继续补齐。
- 五个栏位已满且至少有一件本轮目标装备时，先启动/恢复买方购买，不再将其误判为卖方上架失败。
- 五个栏位全部被无关商品占用时安全暂停，并明确要求人工处理，避免误售或错误推进。
- 人工确认装备所在账号后，恢复模式同时向卖方和买方下发任务；同设备账号会建立联动，买方购买后卖方继续复核和补货。
- 同一件装备在证据暂时不一致时允许最多三轮重新核对；达到上限仍无法确认才进入人工介入。
