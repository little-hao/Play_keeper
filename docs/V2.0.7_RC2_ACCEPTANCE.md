# Play Keeper 2.0.7-rc2 全账号验证说明

本候选版不以单账号结果作为验收结论。待每日副本刷新后，应由用户选择全部账号进行一次完整验证。

## 验收条件

1. 所有账号均完成任务页加载与一键接受验证。
2. 所有账号均完成“已接受的任务”页签扫描；发现的可完成任务全部完成，剩余数量为零。
3. 每个账号生成本轮新的背包快照。
4. 每个账号返回其指定挂机副本并验证挂机已启动。
5. 任一步缺少证据时显示失败或未验证，整轮不得显示成功，也不得自动进入拍卖。
6. 启用邮件时，邮件列出逐账号结果和本用户全部账号背包合计。

## 自动验证

- VPS、协议、恢复、严格证据与邮件汇总测试：70 项。
- Android 单元测试、Lint 和候选 APK 构建由 GitHub Actions 执行。
