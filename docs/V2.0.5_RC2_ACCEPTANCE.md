# Play Keeper 2.0.5-rc2 验收重点

1. 安装 rc2 候选 APK，并部署配套 rc2 VPS 包；保留生产 `.env`、`data/`、计划状态、邮件与诊断配置。
2. 在“当前账号高级操作”选择“情人套装”，卖方 hao7、买方 hao，确认页面显示十件 `.改` 装备。
3. 等待一次设备状态刷新，确认网页仍保留情人套装、价格和买卖方，不回退到厄菲斯神套装。
4. 点击“卖方上架装备”，确认状态先显示等待两端配置，随后才开始上架。
5. 在 APP 及网页状态中确认两端回传的 `equipmentItems` 仍为情人套装，并完成两批最多五件的转移。
6. 若任一端回传不同套装，VPS 应立即暂停，显示网页期望与设备实际清单，不得持续刷新交易所。
7. 回归验证厄菲斯神套装、九件 `§恋§` 套装以及自定义 1–10 件装备仍可正常配置。
