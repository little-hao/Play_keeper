# Play Keeper v1.7.2 — 同名宠物事务定位

## 修复内容

- 副宠取出后按“新增携带卡片索引”定位，不再要求名称、等级和头像组合必须唯一。
- 取出数量与牧场行变化确认后，立即保存 `deputy-withdrawn` 检查点；后续属性核验失败也不会重复取宠。
- 兼容 v1.7.1 遗留的 `pasture-prepared` 检查点：检测到携带栏已增加时，按末尾新增卡片恢复副宠事务。
- 主宠和副宠完全同名、同等级、同头像时，使用副宠事务索引排除主宠卡片。
- 属性读取优先合并 `.user-right` 属性区，保留页面显示的阶级、成长和五行，修复 `tier:null`。

## 恢复当前现场

若 v1.7.1 已经取出副宠但停在 `pasture-prepared`：

1. 不要人工再次取宠。
2. 更新并重新加载 v1.7.2，刷新游戏页。
3. 保持两只携带宠物不变，再启动自动循环。
4. 插件会把末尾新增携带卡片恢复为本次副宠，并推进到 `deputy-levelled`。

恢复失败时会保留现场并记录 `pasture-prepared-index-recovery-rejected`，不会继续取宠。
