# Play Keeper v1.5.8 — 后台尝试、批量进化与合成恢复

## 后台运行

- 新增“允许尝试后台运行（实验）”，默认关闭。
- 默认关闭时，关键点击前若游戏标签页不是活动标签、Chrome 未聚焦或窗口已最小化，扩展会先恢复窗口并激活游戏标签页。
- 实验选项开启后先尝试后台点击；牧场升级弹窗或合成宠物列表首次验证失败时，自动切回前台并只重试一次。
- 诊断包记录标签页是否活动、窗口是否聚焦/最小化，以及页面的 `visibilityState`、`hidden`、`hasFocus()`。
- Windows 锁屏、远程桌面会话断开以及 Chrome 被系统休眠不属于可靠后台运行场景。

## 连续进化

- 每周期仍支持 0–10 次主宠进化。
- 新增“连续进化核验间隔”，默认 5；设置 10 次时默认在第 5、10 次统一返回属性页核验。
- 新增“连续进化期间核验 CC”，默认开启。关闭后不依据批次中的 CC 停止，但仍核验主宠身份、等级和进化次数。
- 每次进化仍必须读到服务器成功消息；批次检查点验证进化次数与实际成功次数一致。

## 合成失败恢复

- 合成失败固定等待从 12 秒改为 5 秒。
- 首先尝试“进化→合成”刷新并恢复主宠、副宠和材料。
- 页面未稳定、下拉为空或选择异常时，只执行一次“中心城镇→右箭头→宠物神殿→合成”完整恢复。
- 同一只副宠的失败重试继续沿用本周期背包快照。

## 使用建议

可靠模式下保持 Chrome 可被恢复到前台。实验后台模式适合窗口被其他应用遮挡的场景，不建议最小化，不支持锁屏后无人值守运行。
