# Play Keeper v1.8.3 — 主战确认框可靠交接

## 修复内容

诊断显示，9+9 合成已经正确升至10阶，新九阶宠物也已成功从牧场取出。中断发生在点击“主战”之后：游戏使用 `.custom-modal` 显示确认框，旧版本没有识别到该类型，随后尝试导航到宠物资料，导航按钮被确认框遮挡。

本版调整如下：

1. 支持识别 `.custom-modal`、标准弹窗和对话框角色。
2. 同时核对“设置主战宠物”标题及确认正文，避免误点其他弹窗。
3. 优先点击 `.custom-modal-btn.confirm`，并保留“确认”文字兼容方案。
4. 点击“主战”后必须找到确认框；找不到时立即停止，不再继续导航。
5. 点击确认后必须验证确认框已经消失；仍有遮挡时立即停止。
6. 只有确认框消失后，才进入宠物资料核验新主战、存放十阶成品和下一轮取宠。

## 建议测试

从一只9阶主宠和一只9阶副宠开始，连续验证至少两次：

`9+9 → 10阶 → 取出新9阶 → 确认为主战 → 存入10阶 → 取出9阶副宠 → 下一轮`

每次换宠均应确认：确认框正常关闭、新主战身份正确、十阶成品进入牧场、携带数量恢复正常。
