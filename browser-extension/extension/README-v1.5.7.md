# Play Keeper v1.5.7 — 合成兼容 Lv40 以上宠物

本版基于 v1.5.6，仅修复自动循环将“至少 Lv40”错误判断为“必须精确 Lv40”的问题。v1.5.6 的普通培养停止 CC 逐轮复核逻辑保持不变。

## 修复内容

- 主宠准备完成条件由 `等级 === 40` 改为 `等级 >= 40`。
- 进化前的主宠等级条件由精确 Lv40 改为至少 Lv40。
- 合成前主宠和副宠均允许 Lv40、Lv41、Lv42 及更高等级。
- 只有宠物低于 Lv40 时才补级或阻止合成。

## 回归重点

- Lv40 主宠与 Lv40 副宠正常合成。
- Lv42 主宠与 Lv41 副宠正常进入合成。
- Lv39 主宠或副宠仍必须先补级，不能绕过安全检查。
