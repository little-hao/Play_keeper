# Play Keeper v1.8.4 — 跨周期副宠快照隔离

## 日志结论

v1.8.3 已成功完成主战确认、九阶新主战验证和十阶成品存放。第二周期中断的原因是上一轮副宠已经成为新主战，但规划器仍保存着旧副宠快照。旧恢复逻辑只按名称判断，因新主战同名而将主宠误恢复成副宠。

## 修复内容

1. 主战交接和十阶成品存放全部验证完成后，清除上一轮副宠快照。
2. 新周期携带栏只有一只宠物时，只能视为主宠，禁止恢复副宠。
3. 仅在携带栏存在第二张以上卡片时检查副宠恢复。
4. 恢复目标必须位于非主宠位置，并同时核对名称与头像。
5. 同名非主宠匹配不唯一时不恢复旧事务，重新进入牧场选择副宠。
6. 诊断日志新增 `stale-deputy-snapshot-ignored`，记录旧快照被忽略的原因。

## 预期流程

`9+9 → 10阶 → 取出新9阶 → 切换主战 → 存入10阶 → 清除旧副宠快照 → 牧场选择另一只9阶副宠 → 下一轮9+9`
