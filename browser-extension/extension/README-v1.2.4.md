# Play Keeper v1.2.4

本版针对用户实机截图修正属性页经验解析。截图及当前浏览器页面文本均明确显示：

- 当前宠物：仙宫玉兔
- 等级：1
- 当前经验：0
- 升级经验：100
- 五行：土
- 成长：2.3

因此 v1.2.3 的“初始经验为 0 的累计经验账本”不是本场景所需方案；v1.2.4 移除该兜底，要求每一步读取游戏页面实时经验值。

## v1.2.4 修复

1. 解析器不再依赖 `等级` 必须位于换行开头；先排除玩家资料里的 `VIP等级`，再解析宠物等级。
2. `宝贝：` 后的宠物名即使位于下一行也能读取。
3. 同时读取 `body.innerText`、`body.textContent`，并扫描可见且同时包含等级/当前经验/升级经验的最小 DOM 区块。
4. 新增“读取经验状态（只读）”按钮。它只读页面，不点击游戏、不消耗道具。预期应显示：`仙宫玉兔 Lv1；当前经验 0/100`。
5. 补级事务在每次使用经验道具前读取实时经验；每次消耗后必须确认背包数量减少，并确认宠物等级/当前经验/升级经验发生变化。任一项无法确认立即停止，不会重试。
6. 移除“人工确认 Lv1 初始经验为 0”的累计经验账本方案；没有实时经验字段时只报诊断，不允许补级。
7. v1.2.2 的只读规划、单次进化/合成框架、可信点击桥保持不变；阶段 3 自动循环仍关闭。

## 推荐验收步骤

1. 在 `chrome://extensions/` 重新加载 v1.2.4，并刷新游戏页。
2. 确认扩展面板标题显示 v1.2.4。
3. 手动选中准备升级的副宠，打开宠物资料“属性”页。
4. 打开背包，确保经验道具列表可见，同时属性页经验数据仍显示。
5. 点击“读取经验状态（只读）”。预期：`Lv1；当前经验 0/100`。这一步不执行任何游戏操作。
6. 只有只读结果正确后，勾选事务确认，再执行“补当前宠到 Lv40”。

## 安全边界

- 补级对象仍然是当前带领宠物，不会自动从牧场取出或切换宠物。
- 仅使用白名单经验道具：200W/500W经验月饼、修炼秘籍（小/中/大）。不使用特大秘籍、5000W月饼或未知道具。
- 每次只使用一件经验道具，并按新读取的实时经验重新规划。
- 若道具数量减少但经验/等级未更新，立即停止，提示人工核对；不会重复点击。
- 本版不自动串联补级、进化、合成；阶段 3 自动循环保持关闭。
