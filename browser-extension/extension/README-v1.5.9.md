# Play Keeper v1.5.9 — 进化状态序列与后台属性同步恢复

## 连续进化

- 每次点击均监听同一提示区域的 DOM 变化，按“进化中 → 进化成功”确认本次结果。
- 相邻两次完全相同的“进化成功”提示不再被误判为旧消息。
- 每次完成后保留至少 1.2 秒间隔，不进行毫秒级连击。
- “宠物已进化十次，无法继续进化”按正常上限处理，不计为失败，随后进入合成。
- 只有到达配置的核验间隔时才返回属性页核验进化次数和可选 CC。

## 后台属性同步恢复

- 根据累计经验推算实际等级，并同时校验升级经验阈值。
- 如果经验与阈值已进入下一等级、等级文字仍停留在旧值，则判定为页面部分更新。
- 此状态下暂停使用道具，先短暂等待；仍不一致时自动切回前台、刷新属性页并重新读取。
- 已经确认库存扣除的经验道具不会再次点击，恢复后从新状态继续。
- 诊断新增 `level/transitional-render-detected` 与 `level/transitional-render-recovered`。
