# Play Keeper v1.5.5 — 自动循环恢复与补级重规划

本版基于 v1.5.4，修复 2026-11-15 三份诊断日志中确认的自动循环问题，不包含已放弃的 v1.5.2 BOSS 刷新功能。

## 修复内容

- 牧场取出副宠后，使用页面特征识别宠物资料页，不再把牧场的通用左右栏布局误认为宠物资料。
- `pasture-prepared` 检查点优先按已保存的牧场行索引恢复，并校验名称、阶级、属性、等级和成长值；兼容任意数量完全相同的宠物。
- 已规划的经验道具行消失时完整重扫背包并重新规划，可安全改用剩余的中、小秘籍等道具。
- 道具消耗后的内部库存采用页面实际剩余数量，不再固定只减一。
- 自动循环在事务间等待时响应用户停止请求，并将结果记录为“已安全停止”，不再误报页面加载失败。

## 建议回归场景

1. 牧场存在多只名称、阶级、属性、等级和成长值完全相同的宠物，确认按检查点保存索引取出目标行。
2. 大秘籍使用至零时，确认脚本重扫背包并根据规划切换到中/小秘籍。
3. 取出副宠后保持在牧场，确认脚本会明确进入宠物资料并打开属性页。
4. 页面稳定等待期间点击停止，确认结果为用户安全停止且错误计数不增加。
