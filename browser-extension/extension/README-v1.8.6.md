# Play Keeper v1.8.6 — 空副宠列表自动换主宠

## 日志结论

两只携带宠物的名称、等级、CC和头像完全一致。合成页按位置选中第一项作为主宠后，页面主宠栏显示正常，但副宠下拉返回0个选项，说明该主宠候选不是游戏当前允许继续选择副宠的实际主战组合。

## 恢复流程

1. 正常选择主宠并尝试打开副宠列表。
2. 仅当副宠列表明确为0项，且主宠列表原本至少有两项时启动恢复。
3. 关闭空副宠窗口。
4. 改选主宠列表中的另一项，并执行主战切换。
5. 重新打开副宠列表并按原事务身份选择副宠。
6. 恢复只执行一次；第二次仍失败则安全中断，不循环切换。

## 安全限制

- 备用主宠仍须匹配目标名称、等级和头像。
- 其他副宠定位错误不会触发该恢复。
- 材料选择和“开始合成”仍须在主副宠完整核验后执行。
