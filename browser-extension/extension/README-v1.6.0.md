# Play Keeper v1.6.0 — 后台进化看门狗与持久诊断

## 本版修复

- 等待进化结果改为按页面实际活动时间计时；Chrome 后台冻结期间经过的墙钟时间不再直接判定超时。
- “进化中”持续 8 秒且标签页不在前台时，自动将游戏窗口和标签页切回前台继续核验。
- 页面没有返回最终提示时不重复点击，改回宠物资料页验证进化次数是否恰好增加 1；验证成功按本次进化成功处理。
- 属性页兜底核验后若批次仍未完成，会重新进入宠物神殿进化页继续剩余次数。
- 同一进化页已选中锁定主宠时复用当前选择，减少重复点击。
- 诊断事件写入当前标签页会话存储，页面刷新后仍可导出；同时记录焦点、可见性、冻结和恢复事件。
- DOM 提示去重，诊断详情在写入时深拷贝，避免后续状态变化污染历史记录。

## 后台运行边界

Chrome 最小化或系统冻结后台标签页时，网页计时器和页面渲染可能暂停。插件会尽量检测停滞并切回前台一次，但无法保证完全无前台运行。建议默认关闭“允许尝试后台运行”；需要稳定长循环时让游戏窗口保持可见。
