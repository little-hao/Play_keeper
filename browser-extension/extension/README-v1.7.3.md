# Play Keeper v1.7.3 — 同名主副宠身份定位

## 本版修复

- 修复携带栏中主宠与副宠名称、等级、头像标识完全相同时，自动循环在启动前报“无法唯一匹配”的问题。
- 主宠复核优先使用页面唯一激活卡片，确认其为当前属性区对应宠物。
- 主战切换或页面刷新后继续沿用原卡位；若卡位变化，则使用唯一激活卡片恢复身份。
- 保留 v1.7.2 的取出顺序、携带位置和事务检查点恢复逻辑。

## 更新与测试

1. 在 Chrome 扩展程序页加载解压后的 v1.7.3 文件夹。
2. 刷新游戏页面，确认规划器标题显示 v1.7.3。
3. 重新锁定主宠、记录背包和牧场并生成规划。
4. 当携带栏存在两只完全相同宠物时，可以直接启动自动循环；当前激活卡片将作为锁定主宠。

> 启动前请确认游戏属性页当前选中的确是锁定主宠。插件不会仅凭相同名称猜测另一张卡片的身份。
