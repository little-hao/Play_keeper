# Play Keeper v1.3.15 — 锁定主宠进化与神殿重试修复

本版开放阶段 3 自动合宠循环，并保留阶段 2 单次事务。自动循环会实时复核主副宠等级、主战身份和每次消耗结果；不可验证的消耗或身份冲突会暂停并保留诊断。

## v1.3.0 新增与修复

### v1.3.15 锁定主宠进化与神殿重试修复

- 单次进化和自动循环进化均只使用“锁定公式主宠”；副宠仅补到 Lv40，不消耗强化丹。
- 自动循环检查点改为“副宠已补级 → 锁定主宠已进化 → 合成就绪”，并兼容旧检查点恢复。
- 合成前实时选中并复核主宠、副宠均为 Lv40，最后恢复锁定主宠为主战再进入合成。
- 宠物神殿入口首次点击后若 12 秒未跳转，只重新定位并重试一次；仍失败即暂停并保留诊断。

### v1.3.14 同等级身份与补级刷新修复

- 主副宠同为 Lv40 时同时校验五行，以及进化次数不变时的 CC，避免属性串宠。
- 经验道具扣除后等待目标卡片刷新为 Lv40，并强制重新选中目标后再核验属性。
- 宠物神殿、进化和合成页面的加载等待延长，适配服务器延迟。
- 保留 v1.3.13 主战切换后的属性稳定核验。

- 主战切换后重新取得最新宠物卡片，并等待属性区名称、等级连续稳定一致。
- 属性同步未完成时不会进入补级、进化或合成，也不会消耗道具。
- 保留 v1.3.12 卡片等级与属性区等级一致性校验。

- 切换宠物后，必须等卡片等级与属性区等级一致并连续稳定，才允许补级或继续自动循环。
- 启动时以当前宠物卡片等级纠正旧快照，避免旧的 Lv1/Lv40 记录阻塞恢复。
- 保留 v1.3.11 主副宠同源快照修复。

- 名称取自当前选中宠物卡片，等级、经验、阶数和 CC 仅取自同一属性块，禁止跨宠物拼接。
- 目标宠物名称缺失或不一致时不再接受“稳定”结果。
- 持久化检查点的副宠等级与实时卡片冲突时自动降级到补级阶段。

- 副宠取出后先核验等级；低于 Lv40 才使用经验道具，Lv40 直接进入进化。
- 选中宠物卡片后额外点击“主战”，并验证玩家“宝贝”字段已切换，之后才进入进化。
- 自动循环检查点写入本地存储，扩展刷新后可恢复已取出、已补级、已进化或待合成阶段。
- 未发现持久化记录但已携带并记录副宠时，按副宠实时等级自动恢复检查点，避免重复取宠。

- 牧场宠物解析改用可见文本，保留名称、等级、阶数和 CC 的换行结构。
- 候选筛选直接关联真实宠物行，避免去重后丢失行索引而无法取宠。
- 无候选时记录模式、有效行数和前 12 条解析结果，便于后续诊断。

- 主宠不足 Lv40 时先执行补级，验证成功后继续当前自动循环检查点。
- 牧场严格按“中心城镇→牧场”进入，并等待异步数量和宠物行实际加载。
- 保存已取副宠、已补级、已进化、待合成检查点；故障恢复后从中止阶段续跑。

- 自动循环先确认锁定主宠已达到 Lv40；不满足时立即停止且不消耗经验道具。
- 主宠成长达到培养停止 CC 时结束，不再取宠或使用材料。
- 从牧场按低阶、低等级、低 CC 顺序取出副宠，临时设为主战后补到 Lv40。
- 此处旧版“副宠进化”行为已由 v1.3.15 覆盖：现在仅进化锁定公式主宠，副宠不使用进化材料。
- 属性页复用当前页面并等待宠物身份、等级和经验字段连续稳定，避免重复导航造成空宠物误判。

- 自动循环改为“牧场取副宠 → 副宠补到 Lv40 → 主宠进化一次 → 重新核验主副宠 → 合成一次”。
- 每个阶段均写入开始/完成检查点，失败保留当前页面和用户接管日志，不自动跨过未验证步骤。
- 进化开始时不再主动点击“离开宠物神殿”；页面不完整时仅切换合成/进化标签安全刷新一次。
- 城镇箭头与宠物神殿入口增加真实命中检测，避免点击被遮挡或不可见的同名 DOM。
- 合成主宠身份改从真实槽位/触发器读取，修复 `:first-child` 误判；主副宠下拉实时等级均达到 Lv40 才可提交。

### v1.3.5 神殿导航、合成恢复与接管日志

- 进入宠物神殿时明确执行“中心城镇第一页右箭头 → 等待第二页 → 宠物神殿”，并分别记录导航事件。
- 合成页点击主宠图标后，若主宠暂时变为“未指定”，自动重新选择已记录主宠并继续；若实际变成另一只宠物仍安全停止。
- 自动循环出错暂停后记录用户接管点击、页面切换和重新开始时间；不记录聊天输入、Cookie或输入框内容。
- 后续 Computer Use 调试可运行自动循环；无法唯一确认的页面保持暂停，等待用户处理后再继续。

### v1.3.4 补级属性快照修复

- 补级开始时先进入属性页读取可信等级与累计经验，再打开背包，不再从背包遮罩后的页面拼接属性字段。
- 每次经验道具库存扣除后，按道具经验值更新事务内快照；全部完成后关闭背包并返回属性页唯一核验 Lv40。
- 自动循环会把已确认的主宠/副宠身份传给补级事务，属性页身份不一致时立即停止。
- 背包等待真实长列表加载后才开始扫描，避免弹窗刚打开时把库存误判为零。

### v1.3.3 背包滚动补级修复

- 补级事务打开背包后逐段扫描实际滚动列表，不再只检查当前可见区。
- 每次使用经验道具前重新滚动定位并确认该行真实可点击，仍找不到时安全暂停。
- 诊断日志新增经验库存滚动扫描结果及滚动容器尺寸，便于后续定位页面变化。

## v1.2.8 基础

- 进化后直接从属性页唯一的“进化次数”字段读取结果，连续稳定后核验恰好 `+1`，不再依赖整页宠物资料解析。

## v1.2.7 基础

### 进化延迟核验

诊断确认旧版把 `null` 经 `Number(null)` 错当成 `0`，属性页尚未加载出“进化次数”时就提前完成读取。

- 未记录进化次数时，事务在点击前停止，绝不再把空值当作 0。
- 进化页最多等待 30 秒，直到宠物列表和强化丹 A/B 两条路径同时完整出现。
- 点击进化后等待 2.5 秒再离开宠物神殿，避免请求仍在处理中就切页。
- 返回主页面和宠物资料最多分别等待 30 秒。
- 属性页最多等待 45 秒，并要求唯一的“进化次数”连续 3 次读取一致才采用。
- 只有进化次数相对事前快照恰好 `+1` 才判定成功；超时、空值、目标变化或计数异常均停止且不重试。

使用前必须在宠物资料 → 属性页等待“进化次数”显示完整，再点击“锁定主宠”。面板摘要中若进化次数仍为“未记录”，进化事务不会点击。

### 合成模式

- 满神：主宠必须十阶；副宠必须八阶及以下；主副宠均须 Lv40。
- 残神：主宠、副宠均必须十阶且 Lv40。
- 公式神宠：主宠和副宠都不限制阶级，但都必须 Lv40。
  - 主宠与副宠都先在规划器记录，摘要显示名称、等级、阶数和 CC。
  - 合成时插件按快照精确选择主宠和副宠；找不到唯一项时停止。

默认材料仍为天神之石 + ★★★成长魂石（绑定版优先）；至尊神石仍只在开关开启且库存/资格预检通过时使用。

## 实机 DOM

- 进化页：`.content-bor1`
  - 宠物列表：`.left-box .li`
  - A/B 路径：`.right-box > .item`
  - 实际进化按钮：路径内 `.ri`
- 合成页：`.content-bor2`
  - 主宠/副宠：自定义 `.pet-popup`
  - 守护/辅助材料：自定义 `.mat-popup`
  - 提交：`uni-button[name="开始合成"]`
- “进化次数”与宠物“阶级”是独立字段。

## 使用顺序

### 进化一次

1. 打开宠物资料 → 属性，等待等级、成长、头像和“进化次数”全部显示。
2. 点击“锁定主宠”，确认摘要中记录了进化次数。
3. 打开背包并点击“记录背包”。
4. 进入宠物神殿 → 进化，等待页面 A/B 内容加载完整。
5. 勾选确认项，点击“进化一次”。

强化丹 A 优先，A 为 0 才使用 B；A/B 都不足时停止，不尝试直接进化。

### 满神 / 残神合成

1. 在宠物资料中锁定主宠、记录副宠，并记录背包。
2. 选择“满神”或“残神”。
3. 进入合成页，勾选确认项，点击“合成一次”。
4. 插件按快照精确选择主宠、副宠和材料，只提交一次。

### 公式神宠合成

1. 选择规划器模式“公式神宠”。
2. 锁定一个 Lv40 主宠并记录一个 Lv40 副宠；两者阶级不限。
3. 进入游戏合成页，勾选确认项，点击“合成一次”。
4. 插件精确选择已记录的主宠、副宠和材料，只提交一次。
5. 若页面显示合成失败，插件仅刷新合成页并恢复选择，不会再次提交。

## 保留功能

- v1.2.5 累计经验与 `万/W` 单位解析修复。
- Lv40 累计经验阈值 `5,633,436`。
- 宠物、材料和路径的唯一匹配保护。
- 阶段 2 单次事务不会串联；阶段 3 只有点击“开始自动循环”后才运行。
- 无法验证道具扣除、宠物身份或页面结果时暂停，不会盲目重复点击。

## 测试与诊断

- “运行 DOM 自检”只读检查当前属性/进化/合成页结构。
- “导出事务诊断”保存版本、规划快照、DOM 摘要、候选匹配、点击阶段及验证结果。
- 日志最多保留当前页面会话最近 1000 条事件，不上传；不包含聊天正文、Cookie、令牌或完整页面 HTML。
- 报错时请先运行 DOM 自检，复现一次后立即导出诊断 JSON，并附页面截图。

## 安装

3. 加载解压根目录；根目录应直接看到 `manifest.json`。
4. 刷新游戏页。
