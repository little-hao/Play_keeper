# Play Keeper v1.2.6 — 真实 DOM 单次进化 / 合成事务

本版基于 `http://sgplay.cc/home.html#/` 实机 DOM 补全“进化一次”和“合成一次”，保留 v1.2.5 的累计经验与“万/W”单位解析修复。阶段 3 自动循环仍关闭。

## 实机 DOM 结论

- 进化页：`.content-bor1`
  - 左侧宠物：`.left-box .li`，通过宠物头像编号精确匹配已锁定主宠。
  - 右侧路径：`.right-box > .item`，A/B 路径分别包含“进化所需材料：强化丹A/B”。
  - 真正的进化点击目标是路径右侧 `.ri` 图片按钮，不是顶部“进化”标签。
- 合成页：`.content-bor2`
  - 主宠/副宠使用自定义 `.pet-popup`，不是原生 `select`。
  - 守护/辅助材料使用自定义 `.mat-popup`。
  - 提交按钮为 `uni-button[name="开始合成"]`。
- 属性页的“进化次数”与宠物“阶级”是两个独立字段：进化事务只检查进化次数，合成资格仍检查阶级。

## 进化一次

1. 目标必须为 Lv40，属性页“进化次数”必须可读且小于 10。
2. 必须先在宠物资料 → 属性页点击“锁定主宠”，记录名称、等级、成长、进化次数和头像标识。
3. 必须先记录背包；执行时强化丹 A 优先，A 为 0 才使用 B。A/B 都不足时停止，不尝试直接进化。
4. 在进化页按头像标识唯一选中目标宠物，再按材料文字唯一选中 A 或 B 路径。
5. 只点击一次进化按钮；随后自动返回宠物资料 → 属性页。
6. 只有同名目标的“进化次数”恰好增加 1 才判定成功。无法核验、目标变化或计数不是 +1 时立即停止且不会重试。

## 合成一次

1. 已记录的主宠、副宠必须均为 Lv40，并继续遵守现有满神/残神阶级资格规则。
2. 脚本依次打开真实主宠/副宠下拉，按“名称 + 等级 + 成长”，并在可用时附加头像标识精确匹配。匹配为 0 个或多个时立即停止。
3. 默认材料：守护使用天神之石，辅助使用 ★★★成长魂石；两者均为绑定版优先，其次非绑定版。
4. 只有“满足最终条件时规划使用至尊神石”开关开启，且现有模式、阶级、CC 和背包库存资格预检全部通过时，守护材料才改为至尊神石。
5. 四个选择结果全部回读一致后，只点击一次“开始合成”。仅在出现可归属于本次事务的唯一结果时完成；无法验证时停止，不会再次点击。

## 保留的 v1.2.5 累计经验修复

- 支持纯整数、千分位、`万`、`W/w` 经验值。
- Lv40 累计经验阈值继续按 `5,633,436` 计算。
- Lv39 页面 `500万 / 563.3万` 继续按累计阈值解析，剩余经验为 `633,436`。
- 每件经验道具仍逐次核验背包扣减和宠物等级/经验变化。

## 使用顺序

### 进化

1. 打开宠物资料 → 属性，选中目标宠物，点击“锁定主宠”。
2. 打开背包并点击“记录背包”。
3. 手动进入宠物神殿 → 进化。
4. 勾选“我已核对当前目标宠物、页面和本次资源选择”。
5. 点击“进化一次”。

### 合成

1. 在显示阶级、等级、成长的宠物资料页分别“锁定主宠”和“记录当前为副宠”。同名宠物必须能由等级/成长/头像唯一识别。
2. 如启用至尊神石，先打开背包并“记录背包”。
3. 手动进入宠物神殿 → 合成。
4. 勾选确认项，点击“合成一次”。

## 安全边界

- 不启用自动循环，也不自动串联补级、进化、合成。
- 页面结构、记录快照和实时选择任一不一致即停止。
- 找不到唯一宠物、材料、路径或提交按钮即停止。
- 点击后的结果无法验证时停止，绝不自动补点第二次。
- 可信点击仍限制在 `sgplay.cc` 游戏页。

## 测试与诊断日志

- “运行 DOM 自检”是只读操作：检查当前属性/进化/合成页的关键容器、下拉数量、两条进化路径和唯一提交按钮，不点击游戏控件。
- “导出事务诊断”下载 JSON，包含版本、规划快照、当前页结构摘要、宠物/材料候选摘要、唯一匹配结果、可信点击阶段和最终验证结果。
- 日志最多保留当前页面会话内最近 300 条事件；刷新页面后重新开始，不进行后台上传。
- 诊断文件不包含聊天正文、聊天输入、Cookie、令牌或完整页面 HTML。
- 后续报错时，请先运行 DOM 自检，再复现一次；停止后立即导出诊断 JSON，连同出错页面截图一起提供。

## 安装

1. 解压发布 ZIP。
2. 在 `chrome://extensions/` 开启开发者模式。
3. 选择“加载已解压的扩展程序”，选择解压根目录；该目录应直接包含 `manifest.json`。
4. 刷新游戏页。
