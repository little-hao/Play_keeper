# Play Keeper v1.4.8 — 背包隔离与进化结果核验

本版修复 v1.4.7 双周期自动循环在进化阶段停止的问题。

## 修复内容

- 背包扫描限定在可见背包弹窗内部，避免把进化页面的“金币 1000、强化丹 A/B”误计为库存。
- 强化丹 A 优先；页面明确提示 A 不足且 B 有库存时，只回退 B 一次。
- 捕获“进化成功 / 进化道具不足”结果；结果未知时不尝试其他路径。
- 属性页仅在进化次数恰好 `+1` 时通过；旧数据先等待，再执行一次宠物资料刷新并复核。
- 保留 v1.4.7 城镇右箭头抖动容错、真实宠物神殿导航、牧场副宠补级、Lv40 核验、合成失败等待及用户接管日志。

## 实测结论

本地 Chrome 中，强化丹 A 路径返回“进化道具不足”，脚本策略随后改用 B；B 路径显示进化成功，属性页延迟加载后确认进化次数从 1 变为 2。

## 安装

1. 解压 `PlayKeeper-Windows-v1.4.8.zip`。
2. 打开 `chrome://extensions/`，开启开发者模式。
3. 选择“加载已解压的扩展程序”，加载解压根目录（根目录直接包含 `manifest.json`）。
4. 刷新游戏页，重新记录背包、牧场并锁定主宠，再开始测试。

## 安全边界

- 单次事务和自动循环均要求确认项。
- 找不到唯一选项、身份不一致或结果无法验证时停止。
- 进化结果未知时不自动换路径；合成结果未知时不自动再次提交。
- 诊断日志保留库存来源、材料路径、页面结果、属性刷新与最终核验信息。
