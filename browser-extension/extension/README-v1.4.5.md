# Play Keeper v1.4.5 — 神殿导航稳定核验修复

本版通过本地 Chrome 真实页面复现并修复“中心城镇已打开，但脚本误点屏外宠物神殿入口”的问题。保留 v1.4.4 的经验道具双证据核验、牧场预升级、合成前主副宠 Lv40 核验、锁定主宠进化选择与诊断日志。

## v1.4.5 城镇翻页与宠物神殿定位

- 城镇第一页和第二页的入口会同时保留在 DOM；脚本不再仅凭元素存在和尺寸判断页面。
- 点击中心城镇后，右箭头或宠物神殿入口必须连续三次保持相同位置，才允许继续。
- 可点击区域会与浏览器视口及所有裁切父容器求交集；完全在屏外、被地图裁切或被其他游戏元素遮挡的入口不会再被选中。
- 可信点击不再固定使用元素中心点；规划器临时让出点击后，会在元素实际暴露区域内重新选择安全点击点。
- 每次翻页后重新读取宠物神殿节点与坐标，避免复用翻页前的旧元素。
- 诊断日志新增 `navigation/town-page-stable` 和稳定位置签名，便于核对真实翻页路径。

## v1.4.4 慢加载与安全核验

- 经验道具点击后的背包数量验证由 5.5 秒延长到 12 秒。
- 背包数量没有及时刷新时，不重复点击同一道具；自动关闭背包并读取目标宠物属性，用“等级增加或经验增加”作为第二证据。
- 第二证据需连续三次稳定一致才算成功；库存与宠物进度都无法验证时立即停止。
- 每两次经验道具操作之间增加 1.8 秒间隔，降低服务器与页面异步刷新冲突。
- 牧场页面现在必须同时加载“牧场数量、宠物列表、当前携带数量”才视为就绪。
- 取出副宠前额外等待携带数量字段，避免页面加载过快时把未知数量误判为异常。
- 诊断日志新增 `verificationSource`，可区分“库存减少”与“宠物进度变化”两种成功证据。

## v1.4.3 合成阶段修复

- 合成预检扫描背包后，不再假定仍停留在神殿；脚本会重新执行“中心城镇→右箭头→宠物神殿→合成”。
- 合成页必须连续三次检测到主宠、副宠、两组材料和“开始合成”按钮后才继续。
- 合成失败后先等待 12 秒冷却，再重新进入神殿并恢复主副宠与材料；下一次自动重试额外等待 15 秒。
- 合成结果读取等待由 15 秒延长到 25 秒，避免慢加载被误判。

## v1.4.2 界面、取宠和合成材料

- 神宠规划器可拖动；自动捕捉默认隐藏，由规划器内“显示自动捕捉”按钮按需打开，也可独立拖动。
- 运行提示移入可拖动的半透明浮动框，减少对游戏页面和规划信息的遮挡。
- 牧场取出副宠改为三重验证：携带数量增加、牧场总数/行数减少、目标宠物行减少；随后还会在宠物资料页核验携带身份与 Lv40。
- 自动循环会复核已保存检查点中的副宠是否仍在携带栏；旧状态不一致时安全回到牧场准备阶段。
- 守护材料与辅助材料可在规划器中自定义，默认分别为“天神之石”和“★★★成长魂石”；同名资源优先选绑定版本，不足时再选非绑定版本。

## v1.4.1 资源选择与异步验证

- 同名的“绑定”和“非绑定”资源均可使用，不再要求名称完全唯一。
- 选择顺序固定为：同名绑定资源→同名非绑定资源。
- 牧场升级弹窗关闭后，先等待对应宠物行的等级刷新；若等级未变，再重开弹窗验证实际选中的绑定状态库存 `-1`。
- 日志记录本次消耗的资源是否绑定，便于后续定位问题。

## v1.4.0 牧场副宠预升级

- 每次启动自动循环前重新复核锁定主宠，并刷新完整背包与牧场快照。
- 新增“牧场升级数量”，默认 `1`，可按实际经验库存和牧场容量自定义。
- 新增“牧场最高阶数”，范围 `1–10`，默认 `8`；默认不包含九阶。
- 候选顺序固定为“低阶 → 低 CC → 牧场原顺序”。
- 规划结果显示白名单经验道具最多可供多少只符合阶数条件、低于 Lv40 的牧场宠物升级。
- 新增“牧场副宠补级”按钮：在牧场升级弹窗内逐次点击经验道具，不使用批量选择；每次点击必须验证库存 `-1` 或等级增加。
- 牧场补级不会把副宠设为主战。补级到 Lv40 后再取出，原锁定主宠保持主战身份。
- 每周期主宠进化次数范围 `0–10`，默认 `1`；实际执行不会超过主宠剩余可进化次数。
- 自动循环流程更新为：`复核主宠/背包/牧场 → 牧场副宠补到 Lv40 → 取出副宠 → 核验主副宠 Lv40 → 仅锁定主宠进化 N 次 → 合成一次`。
- 牧场预升级、逐次经验消耗和每次主宠进化均写入检查点与事务诊断；刷新或人工接管后可从已确认阶段继续。

### 使用顺序

1. 在宠物资料“属性”页锁定主宠。
2. 记录背包、记录牧场；也可由自动循环启动预检自动刷新。
3. 设置牧场升级数量、最高阶数和每周期主宠进化次数。
4. 可先勾选确认项并点击“牧场副宠补级”单独执行；或直接开始自动循环。
5. 同名经验道具出现多个无法唯一选择、库存变化无法验证、宠物等级未达到 Lv40 时，脚本立即暂停，不会猜测或重复消耗。

### 经验计算边界

- 仅自动使用白名单经验道具：`500W经验月饼`、`200W经验月饼`、`修炼秘籍（大/中/小）`。
- 牧场页不显示完整累计经验，因此低于 Lv40 的候选按保守的 Lv1→40 阈值 `563.3W` 预留经验；可能比宠物实际剩余需求略高，但避免经验不足。
- 神秘糖果、修炼秘籍（特大）、好运奖券、牛奶、修炼仙册等未确认经验值的物品不会自动使用。

## v1.2.7 基础

### 进化延迟核验

诊断确认旧版把 `null` 经 `Number(null)` 错当成 `0`，属性页尚未加载出“进化次数”时就提前完成读取。

- 未记录进化次数时，事务在点击前停止，绝不再把空值当作 0。
- 进化页最多等待 30 秒，直到宠物列表和强化丹 A/B 两条路径同时完整出现。
- 点击进化后等待 2.5 秒再离开宠物神殿，避免请求仍在处理中就切页。
- 返回主页面和宠物资料最多分别等待 30 秒。
- 属性页最多等待 45 秒，并要求唯一的“进化次数”连续 3 次读取一致才采用。
- 只有进化次数相对事前快照恰好 `+1` 才判定成功；超时、空值、目标变化或计数异常均停止且不重试。

使用前必须在宠物资料 → 属性页等待“进化次数”显示完整，再点击“锁定主宠”。面板摘要中若进化次数仍为“未记录”，进化事务不会点击。

### 合成模式

- 满神：主宠必须十阶；副宠必须八阶及以下；主副宠均须 Lv40。
- 残神：主宠、副宠均必须十阶且 Lv40。
- 公式神宠：主宠和副宠都不限制阶级，但都必须 Lv40。
  - 主宠与副宠都先在规划器记录，摘要显示名称、等级、阶数和 CC。
  - 合成时插件按快照精确选择主宠和副宠；找不到唯一项时停止。

默认材料仍为天神之石 + ★★★成长魂石（绑定版优先）；至尊神石仍只在开关开启且库存/资格预检通过时使用。

## 实机 DOM

- 进化页：`.content-bor1`
  - 宠物列表：`.left-box .li`
  - A/B 路径：`.right-box > .item`
  - 实际进化按钮：路径内 `.ri`
- 合成页：`.content-bor2`
  - 主宠/副宠：自定义 `.pet-popup`
  - 守护/辅助材料：自定义 `.mat-popup`
  - 提交：`uni-button[name="开始合成"]`
- “进化次数”与宠物“阶级”是独立字段。

## 使用顺序

### 进化一次

1. 打开宠物资料 → 属性，等待等级、成长、头像和“进化次数”全部显示。
2. 点击“锁定主宠”，确认摘要中记录了进化次数。
3. 打开背包并点击“记录背包”。
4. 进入宠物神殿 → 进化，等待页面 A/B 内容加载完整。
5. 勾选确认项，点击“进化一次”。

强化丹 A 优先，A 为 0 才使用 B；A/B 都不足时停止，不尝试直接进化。

### 满神 / 残神合成

1. 在宠物资料中锁定主宠、记录副宠，并记录背包。
2. 选择“满神”或“残神”。
3. 进入合成页，勾选确认项，点击“合成一次”。
4. 插件按快照精确选择主宠、副宠和材料，只提交一次。

### 公式神宠合成

1. 选择规划器模式“公式神宠”。
2. 锁定一个 Lv40 主宠并记录一个 Lv40 副宠；两者阶级不限。
3. 进入游戏合成页，勾选确认项，点击“合成一次”。
4. 插件精确选择已记录的主宠、副宠和材料，只提交一次。
5. 若页面显示合成失败，插件仅刷新合成页并恢复选择，不会再次提交。

## 保留功能

- v1.2.5 累计经验与 `万/W` 单位解析修复。
- Lv40 累计经验阈值 `5,633,436`。
- 宠物、材料和路径的唯一匹配保护。
- 阶段 2 单次事务不会串联；阶段 3 只有点击“开始自动循环”后才运行。
- 无法验证道具扣除、宠物身份或页面结果时暂停，不会盲目重复点击。

## 测试与诊断

- “运行 DOM 自检”只读检查当前属性/进化/合成页结构。
- “导出事务诊断”保存版本、规划快照、DOM 摘要、候选匹配、点击阶段及验证结果。
- 日志最多保留当前页面会话最近 1000 条事件，不上传；不包含聊天正文、Cookie、令牌或完整页面 HTML。
- 报错时请先运行 DOM 自检，复现一次后立即导出诊断 JSON，并附页面截图。

## 安装

1. 解压 ZIP。
2. 在 `chrome://extensions/` 开启开发者模式。
3. 加载解压根目录；根目录应直接看到 `manifest.json`。
4. 刷新游戏页。
