# Play Keeper v1.7.1 — 十阶主宠自动交接

## 本版补齐

- 主宠升到十阶后，自动从牧场选择配置阶数范围内的新主宠。
- 新主宠低于 Lv40 时先沿用现有经验规划补级，再取出。
- 逐张打开携带宠物属性，按名称、阶数、等级、成长和头像建立身份记录。
- 将新主宠设为主战后重新读取全部身份，避免主战切换造成卡片顺序变化。
- 返回牧场选择旧十阶主宠并点击“存放”。
- 存放结果必须同时满足：携带数量减少、牧场数量增加、旧十阶宠物重新出现在牧场。
- 完成交接后重新锁定新主宠，并从下一个升阶周期继续。

## 实测得到的页面规则

- 牧场右侧携带卡片的角标表示当前选中卡片，不代表主战状态。
- “主战”和“存放”都会触发牧场区域异步刷新，不能在点击后立即依据旧 DOM 判定失败。
- 牧场携带卡片只显示头像；完整身份必须到宠物资料属性页逐张读取。
- 同名同头像宠物可以通过阶数、等级和成长进一步区分；仍不唯一时脚本会停止。

## 安全验证

取出、设为主战和存放均通过数量及身份的组合验证。任一验证失败时保留现场，不继续下一周期。
