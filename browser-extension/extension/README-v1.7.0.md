# Play Keeper v1.7.0 — 同阶合成升阶

## 新增功能

- 新增“合成升阶”模式，默认允许选择 7–9 阶主宠。
- 每轮只从牧场选择与当前主宠同阶的副宠，主副宠均须达到 Lv40。
- 升阶模式默认跳过进化材料与进化步骤。
- 合成成功后返回宠物资料属性页读取真实阶数；成功但未升阶时继续同阶合成。
- 合成成功消息优先于合成页刷新/下拉项的旧错误，后续由属性页核验最终结果。
- 新增升阶统计：确认升阶、成功但阶数未变、换主宠次数。
- 面板改为“核心设置 / 高级设置 / 准备数据 / 自动执行”分区，非必要设置默认收起。

## 使用流程

1. 在宠物资料属性页选择准备升阶的主战宠物，点击“锁定主宠”。
2. 打开背包和牧场，分别点击“记录背包”“记录牧场”。
3. 模式选择“合成升阶”，设置起始阶数范围；默认 7–9 阶。
4. 勾选事务确认，设置最多周期及单只合成重试上限，启动自动循环。
5. 插件会选择同阶副宠、补到 Lv40、取出并合成；每次成功后以属性页阶数为准。

## 安全边界

- 当前版本在主宠达到十阶时会保留现场并停止，避免在牧场存在重名宠物时错误存放。自动换主宠和存放旧十阶主宠将在完成更多身份定位样本后开放。
- 浏览器后台运行仍为实验功能，默认关闭；关键点击后均进行结果验证。
