# Play Keeper v1.7.4 — 同名主副宠合成卡位消歧

## 修复内容

- 修复主宠与副宠名称、等级、成长、头像标识完全相同时，合成弹窗无法唯一选择主宠的问题。
- 宠物资料页确认主宠时记录其携带栏位置。
- 副宠继续沿用牧场取出后保存的携带栏位置。
- 合成弹窗出现重复身份时，按已经确认的携带位置选择对应项。
- 使用位置消歧前仍会复核名称、等级和头像标识；任一字段冲突都会停止，不会盲目点击。
- 诊断包新增 `synthesis/pet-position-disambiguated` 事件，记录本次按卡位恢复的角色和选项。

## 测试方式

更新并刷新游戏页，确认规划器显示 v1.7.4。重新锁定主宠、记录背包和牧场后启动循环。同名宠物场景中，主宠应取携带位 0，副宠应取已记录的携带位 1，并继续提交合成。
