# Play Keeper v1.2.2

本版针对 v1.2.1 实机测试发现的两个问题修复：

1. **规划输出错位 / 看起来没有生成规划**
   - v1.2.1 的“生成规划”按钮和规划输出区共用了 `.plan` 类。
   - 规划结果因此可能被写入按钮本身，造成超大按钮、空白区和布局错位。
   - v1.2.2 改为 `.plan-button` 与 `.plan-output`，规划结果固定显示在“自动规划结果”折叠区中。
   - 主宠 + 牧场 + 背包三份快照齐全后立即自动更新规划，不再依赖轮询等待。

2. **属性页能够看到等级/经验，但补级事务提示未读取到宠物资料**
   - sgplay.cc 的“属性”页实测显示：等级、当前经验、升级经验、成长等，但不一定显示阶级。
   - v1.2.1 使用完整宠物解析器，要求“等级 + 阶级 + 成长”同时存在，因此会误判。
   - v1.2.2 新增属性页进度解析器：补级只要求“等级 + 当前经验 + 升级经验”。
   - 完整主宠/副宠快照中的阶数和 CC 仍单独保留，用于进化/合成预检。

## UI 调整

- 面板宽度调整为 350px。
- “自动规划结果”成为独立折叠区，最大高度 330px，内部单独滚动。
- 新增“收起 / 展开”按钮；收起后只保留标题栏，便于查看宠物资料、背包弹窗和游戏内容。
- 单次事务区仍在同一面板内，但不再参与规划按钮的 Grid 布局。

## v1.2.2 推荐测试顺序

1. 打开“宠物资料 → 属性”，确认页面有：等级、当前经验、升级经验。
2. 若当前宠物是副宠，点“记录当前为副宠”（完整副宠快照仍建议在能看到阶数/成长的页面记录）。
3. 打开牧场，点“记录牧场”。
4. 打开背包，点“记录背包”。
5. 三份快照齐全后，“自动规划结果”应立即更新。
6. 点击面板顶部“收起”，确认不会继续遮挡游戏弹窗。
7. 测试“补当前宠到 Lv40”：属性页的等级/经验解析不再要求阶数字段。

## 安全限制保持不变

- 阶段 2 每次只执行一个事务。
- 进化一次 / 合成一次不会自动循环。
- 合成前主宠、副宠均必须记录且达到 Lv40。
- 阶段 3 自动循环仍关闭。
