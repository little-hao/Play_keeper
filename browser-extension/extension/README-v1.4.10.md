# Play Keeper v1.4.10 — 异步核验与牧场断点续跑

## 本版修复

- 主宠经验道具已扣除后，宠物卡片若仍显示旧等级，会刷新宠物资料并延长核验；属性页已稳定确认达到 Lv40 时，不再因卡片延迟误报失败。
- 合成守护/辅助材料弹层允许异步加载并安全重试一次；弹层已打开但选项仍在加载时不会反复点击开关。
- 牧场副宠补级按宠物当前等级重新估算保守剩余经验。中断后已到 Lv39 的宠物不再重新套用整套 Lv1→40 方案。
- 牧场恢复目标时使用名称、阶数、成长和五行作为稳定身份；等级变化不再导致目标丢失。
- 牧场升级弹窗关闭后等待列表异步刷新，并在每次点击前重新定位绑定/非绑定道具行，绑定资源仍优先。
- “牧场副宠补级”已从阶段 2 移到“记录背包 / 记录牧场”操作区。

## 自动循环前必做

1. 在宠物资料页锁定主宠。
2. 打开背包并点“记录背包”。
3. 打开中心城镇 → 牧场并点“记录牧场”。
4. 建议先勾选事务确认项，再点“牧场副宠补级”，把计划数量的低阶副宠提前升到 Lv40。
5. 重新记录牧场并生成规划，然后开始自动循环。

提前完成牧场补级可以减少每周期的页面切换和等待时间。补级、身份或资源消耗无法唯一验证时，脚本仍会停止并保留诊断，不会盲目重复点击。

## 安装

1. 解压 `PlayKeeper-Windows-v1.4.10.zip`。
2. 打开 `chrome://extensions/`，开启开发者模式。
3. 选择“加载已解压的扩展程序”，指向解压根目录；该目录应直接包含 `manifest.json`。
4. 刷新游戏页面，按上面的前置步骤重新记录数据。
