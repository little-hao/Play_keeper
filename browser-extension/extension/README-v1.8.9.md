# Play Keeper 浏览器扩展 v1.8.9

本版本修复合成弹窗中目标主宠位于第二项时被误判为身份不一致的问题，并缩短副宠空列表恢复等待。

## 修复

- 普通主宠选择的 `forcedOptionIndex=null` 不再被转换为索引 `0`。
- 目标主宠位于第二项时继续按名称、等级、成长值及既有身份规则匹配。
- 强制索引只接受明确传入的非负整数，仅用于空副宠恢复阶段的主宠换位。

## 等待优化

- 副宠弹窗出现后立即观察选项和加载状态。
- 弹窗至少可见 1.5 秒，且 DOM 连续稳定为空 1 秒后才判定为空。
- 保留 5 秒硬上限，避免页面异常时无限等待。
- 空列表会记录 `synthesis/pet-options-stable-empty`；超时会记录 `synthesis/pet-options-wait-timeout`。

其余合成身份校验、可见关闭按钮恢复和合成结果验证规则保持不变。
