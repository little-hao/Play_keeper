# Play Keeper v1.5.3 — 牧场补级与检查点修复

v1.5.3 从 v1.5.1 分支直接升级，不包含已放弃的 v1.5.2 BOSS 刷新功能。

## 修复

### 牧场补级提速

- 经验道具已确认库存 `-1` 时，立即认定本步成功，不再额外等待等级变化。
- 升级弹窗自动关闭后，牧场列表的快速等级确认从 12 秒缩短为 1.5 秒；未更新时立即重开弹窗核对库存。
- 只有无法确认库存扣减时，才保留较长的等级/页面同步验证。
- 仍保留逐件点击、逐件验证，不进行批量盲点。

### 过期 `pasture-prepared` 检查点恢复

- 自动循环恢复已准备的副宠前，先扫描当前牧场。
- 牧场没有目标时再检查携带栏：
  - 携带栏存在且等级不低于 Lv40：跳过重复取出，继续后续阶段。
  - 牧场和携带栏都不存在：判定为过期检查点，清除旧目标并按当前牧场重新选择。
  - 牧场匹配到多个相同身份：保持安全暂停，不自动猜测。
- 携带栏确认由只接受 `Lv40` 改为接受 `Lv40 及以上`。
- 自动循环新增"清除旧检查点，从当前牧场重新开始"选项。

## 建议测试

1. 先将"牧场升级数量"设为 1，执行一次"牧场副宠补级"。
2. 核对每件经验道具只扣除一个，最终确认该宠物达到 Lv40。
3. 选中"清除旧检查点"，用一个周期测试自动循环。
4. 再不选中该选项中断并继续一次，验证有效检查点仍能恢复。
5. 若暂停，导出新的事务诊断 JSON。
