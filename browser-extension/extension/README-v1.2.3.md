# Play Keeper v1.2.3

本版修复 v1.2.2 在 sgplay.cc 实机测试时出现的补级失败。

## 根因

实机页面读取结果显示，宠物属性区域提供：

- 当前带领宠物名称
- 等级
- 五行
- 阶级
- 成长/CC

但当前页面 DOM **没有**“当前经验”和“升级经验”字段。v1.2.2 错误地要求必须读取这两个字段，因此即使已经打开宠物属性页，仍会提示“未读取到当前经验/升级经验”。

## v1.2.3 修复方式

- 不再提示用户反复切换属性页寻找页面中不存在的经验字段。
- 当当前宠物等级为 Lv1、经验字段缺失时，增加单独的人工确认项：
  - “若当前宠物为 Lv1：我确认其初始经验为 0（游戏页面不显示经验字段）”
- 只有勾选通用事务确认 + Lv1 零经验确认，才允许开始补级。
- 使用已核对的 Lv1→Lv40 经验曲线，按本轮实际消耗的白名单经验道具累计经验，估算当前等级与剩余经验。
- 每次使用一个经验道具后，先确认对应库存数量减少，再把该道具经验记入账本，并核对游戏页面等级是否与曲线预计一致。
- 若页面等级与累计经验曲线不一致、宠物身份变化、道具消耗无法确认，立即停止，不会自动重试。
- 事务成功后清除本轮累计经验账本；事务中断时仅在当前页面会话内保留账本，防止同一页面内重复计算已消耗经验；刷新/关闭游戏标签页会清空账本，若中断后已消耗道具，必须先人工核对，不要直接刷新后重试。

## 安全边界

1. **仅支持页面不显示经验字段时，从 Lv1 且初始经验为 0 开始补级。**
2. 如果当前宠物已经是 Lv2 或更高、但页面仍不显示当前经验/升级经验，v1.2.3 会停止。因为无法知道当前等级已经累积了多少经验，不能安全估算。
3. 如果 Lv1 宠物实际上已经获得过经验，不要勾选“初始经验为0”。请先人工核实，避免超量使用经验道具。
4. 每次只使用一个经验道具；不使用未知道具，不使用“修炼秘籍（特大）”、神秘糖果、5000W月饼等非白名单道具。
5. 每次使用后必须确认库存减少，并校验页面等级与累计经验曲线一致。
6. 阶段 2 仍然是单次事务；进化一次/合成一次不会自动循环；阶段 3 自动循环保持关闭。

## 本次测试覆盖

- 解析当前实机属性页文本（没有当前经验/升级经验字段）。
- Lv1 零经验曲线估算。
- 使用 500W 后预计 Lv39、剩余 633,436 经验。
- 累计 565W 后预计达到 Lv40。
- 原有规划、经验组合、阶数筛选、进化/合成预检测试。

## 安装

1. 在 `chrome://extensions/` 停用/移除旧 v1.2.2。
2. 解压 ZIP。
3. 点击“加载已解压的扩展程序”，选择直接包含 `manifest.json` 的目录。
4. 刷新 `http://sgplay.cc/home.html#/`。
5. 打开宠物资料，确认当前带领宠物身份和等级；打开背包。
6. 勾选“我已核对当前目标宠物、页面和本次资源选择”。
7. 若当前宠物为 Lv1 且确认初始经验为 0，再勾选第二项确认。
8. 点击“补当前宠到 Lv40”。

注意：本版不会自动把牧场中的副宠取出，也不会自动切换当前带领宠物。请先手动取出并切换为当前带领宠物，再执行补级。
