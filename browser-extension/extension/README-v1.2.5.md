# Play Keeper v1.2.5 — 累计经验 / 万单位解析修复

## 本版根据实机测试修复

实机页面已验证：

- Lv1：当前经验 `0`，升级经验 `100`
- 使用 500W 经验月饼后：宠物达到 Lv39
- Lv39 页面显示：当前经验 `500万`，升级经验 `563.3万`
- 达到 Lv40 的累计经验阈值约为 `563.3W`；规划按内部精确曲线 `5,633,436` 经验计算，并确保使用经验不低于阈值。

## v1.2.4 的问题

旧版有两个口径错误：

1. 把页面显示的 `500万 / 563.3万` 当作普通整数，导致 `563.3万` 被截取成 `563`。
2. 把页面的“升级经验”当成单级增量。实际上属性页显示的是累计经验阈值；Lv39 的 `563.3万` 应与 Lv1→Lv39 的累计阈值比较，而不是与单级增量 `804667` 比较。

## v1.2.5 修复

- 经验解析支持纯整数、千分位、`万`、`W/w`，统一换算为实际经验值。
- 建立逐级累计经验阈值表；实时页面值与累计阈值允许 1000 点显示舍入误差。
- Lv40 剩余经验按 `5,633,436 - 当前累计经验` 计算。
- Lv39 示例：`5,633,436 - 5,000,000 = 633,436`，即约 `63.3W` 尚需经验。
- 经验规划默认目标改为 `563.3W`；组合优化按可用道具的整数 W 面额计算，确保总量达到目标。
- 已有 v1.2.4 配置若仍为默认 `564W`，自动迁移到 `563.3W`。
- 补级事务在页面确认 Lv40 后即可结束，不再要求 Lv40 页面继续显示“升级经验”。
- 经验读取状态统一显示 W 单位，方便人工核对。

## 安全边界

- “读取经验状态（只读）”不点击游戏、不消耗道具。
- 补级仍是阶段 2 单次事务；每次只使用一件道具，核对背包扣减和宠物经验/等级变化，再重新计算。
- 无法读取、页面数据与累计阈值不一致、库存扣减无法确认或宠物状态无法验证时立即停止。
- 阶段 3 自动循环仍关闭。

## 安装

1. 在 `chrome://extensions/` 移除旧版扩展，或停用后加载新版本目录。
2. 解压 ZIP，选择根目录（应直接看到 `manifest.json`）。
3. 点击扩展“重新加载”，刷新 `http://sgplay.cc/home.html#/`。
4. 打开宠物资料的“属性”页和背包，先点“读取经验状态（只读）”。
5. 确认显示的等级、当前经验和升级阈值正确后，再考虑执行单次补级。
