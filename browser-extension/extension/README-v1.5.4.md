# Play Keeper v1.5.4 — 牧场实际补级计数修复

## 问题

牧场同时存在同名、同阶、同属性、同 CC 的 Lv1 和 Lv40 宠物时，v1.5.3 会把 Lv40 行误当成 Lv1 目标升级后的结果。已有 Lv40 被重复选中，却被计入"牧场升级数量"。

## 修复

- 恢复和选择牧场目标时，先使用 `pastureIndex` 锁定规划中的真实行。
- 行索引不可用时，先匹配相同起始等级，最后才使用"等级已进展"恢复逻辑。
- `upgradePasturePet` 返回起始等级、已验证道具次数和是否真正完成升级。
- 只有"起始等级低于40 + 至少一次道具消耗验证 + 最终达到40级"才计入完成数。
- 已有 Lv40 被意外选中时立即停止并报告，不再伪造完成数。
- 每只完成后记录牧场行标识，不会在同一轮重复计数。
- 结果显示"请求 N 只，实际完成 N 只从低于 Lv40 升至 Lv40"。

## 建议测试

1. 保留一组同名、同阶、同属性、同 CC 的 Lv1/Lv40 宠物。
2. 先设置升级数量为1，确认选中 Lv1 行并有真实道具扣减。
3. 再设置为3，确认三只不同的低等级宠物分别达到 Lv40。
4. 核对诊断日志中每只都有 `pasture-upgrade/consumption-verified`、`pet-complete` 和 `completed-counted`。
