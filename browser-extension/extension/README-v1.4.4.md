# Play Keeper v1.4.4 — 慢加载双重核验修复

本版针对自动循环中“经验道具已生效但背包数量尚未刷新”和“牧场列表先于携带数量加载”的异步问题进行修复。原有主副宠 Lv40 预检、仅锁定主宠使用进化材料、合成材料设置、合成失败冷却重试及事务诊断均保持不变。

## 本版修改

- 经验道具库存减少等待由 5.5 秒延长到 12 秒。
- 库存没有及时刷新时，脚本不会重复点击；转到宠物属性页，用等级或经验增加作为第二成功证据。
- 宠物进度必须连续三次稳定一致才通过；两种证据均无法确认时安全停止。
- 每次经验道具使用后等待 1.8 秒，再规划下一次使用。
- 牧场页面需同时识别牧场数量、宠物列表和当前携带数量，才允许继续取宠。
- 取宠前再次等待携带数量加载，避免出现“未知/3”的误停。
- 诊断日志记录 `verificationSource`，方便区分库存验证和属性进度验证。

## 手动测试建议

1. 在扩展管理页加载 v1.4.4 文件夹或 ZIP 解压后的目录。
2. 记录背包、牧场并锁定主宠，勾选确认项。
3. 将最多周期设为 `1`，执行一个自动循环。
4. 重点观察 Lv39 补级时是否只消耗一次计划道具，以及牧场取宠是否等待携带数量出现。
5. 若停止，导出事务诊断；不要人工重复点击刚才未确认的经验道具。

## 安装包结构

发布 ZIP 根目录直接包含 `manifest.json`，可解压后通过 Chrome“加载已解压的扩展程序”安装。
