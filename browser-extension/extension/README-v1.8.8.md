# Play Keeper v1.8.8 — 同身份宠物合成恢复

本版基于 v1.8.7，修复主宠与副宠名称、等级、成长和头像相同时，选择主宠后副宠弹窗短暂或持续显示“暂无可选项”导致自动循环中断的问题。

## 恢复流程

1. 选择并激活主宠，等待合成页稳定重渲染。
2. 打开副宠列表；若为空，使用当前可见的“关闭”按钮关闭弹窗后重开。
3. 再次为空时，在“进化/合成”标签间切换以重建合成页，并恢复原主宠。
4. 重建后仍为空时，改选另一个通过完整身份校验的主宠候选，让原主宠成为唯一剩余副宠。
5. 重新核验主副宠等级和身份后继续选择材料与合成。

插件不会再尝试点击被遮罩覆盖的副宠下拉框。恢复次数有明确上限，全部失败后安全暂停，不会无限刷新或随意选择宠物。
