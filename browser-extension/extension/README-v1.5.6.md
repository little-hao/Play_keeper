# Play Keeper v1.5.6 — 普通培养停止 CC 逐轮复核

本版基于 v1.5.5，修复普通培养停止 CC 仅在自动循环启动时检查一次的问题。

## 修复内容

- 自动循环启动前读取主宠实时 CC，已经达标时不执行补级、取副宠或合成。
- 每轮合成成功后立即重新进入宠物属性页并读取实时 CC。
- 下一轮开始、主宠补级和取副宠之前增加保险复核。
- 达到或超过停止值时保留 `complete` 检查点，以“已达到培养目标”正常结束，不计为错误。
- 主宠 CC 等于停止值时同样判定为达标，统一规划器与自动循环的 `>=` 语义。
- 日志新增 `automation/target-cc-check`，包含阶段、轮次、实时 CC、停止值和判断结果。

单次合成可能令 CC 略微超过停止值，这是一次合成的正常增量；达标后不会继续下一轮。
