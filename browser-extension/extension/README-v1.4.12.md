# Play Keeper v1.4.12 — 单宠固定经验组合与合成续轮

## 本版修复

### 牧场副宠补级

- 每只副宠开始补级时，根据当时等级和可用库存生成一份固定经验组合。
- 从当前等级到 Lv40 的整个过程沿用该组合，不再因等级变化重复计算剩余经验。
- 每次道具点击仍逐项验证库存减少或等级增加，防止误点和重复消耗。
- 只有当前副宠确认达到 Lv40 后，才刷新牧场和剩余库存，为下一只副宠生成新组合。
- 如果用户在中途刷新页面或重新加载扩展，原固定组合无法从游戏页面还原，插件会按当前等级和库存重新规划并继续采用安全停止原则。

### 合成后的下一周期

- 合成成功后，同名新主宠可能回到 Lv1，并改变成长、CC和进化次数。
- 下一周期选择主战宠物时以名称、卡片和实时等级确认身份；CC与进化次数改为重新读取，不再沿用合成前旧值拒绝同名新宠。
- 宠物名称不唯一、卡片不唯一或实时属性无法稳定读取时仍立即暂停。

### 保留行为

- 自动循环中强化丹 A/B 均不足时，跳过本周期剩余进化次数并进入合成；单次“进化一次”仍安全停止。
- 合成前继续确认主宠和副宠均达到 Lv40，并保持材料唯一匹配、失败冷却和结果验证。
- 保留 v1.2.5 累计经验修复及现有诊断日志。

## 日志结论

- `17-35-01` 日志显示同一只小幽灵欧姆已执行大额经验道具并升至 Lv37，随后旧版按 Lv37 重新生成计划，只看到剩余 15W，错误报告需要 163.3W。本版不再在单宠过程中重算。
- `17-38-50` 日志显示合成已成功，下一周期同名鬼精灵欧姆变为 Lv1、CC 54、进化 0；旧版仍用合成前 CC 52.7 等字段核验，导致“属性区未稳定一致”。本版把这些字段作为合成后可变状态重新读取。

## 授权与防二次传播建议

浏览器扩展可以增加激活码或授权服务器，但只在扩展内保存密钥、加密或混淆脚本，不能可靠阻止解包、复制和修改。推荐采用服务端授权：账号或设备激活后签发短期令牌，扩展只内置公钥并定期续期；如使用 Chrome 应用商店，可同时限制为指定测试账号。此功能未在 v1.4.12 中启用，避免在未确定服务器、账号策略、离线时限和隐私说明前加入不可维护的授权逻辑。
