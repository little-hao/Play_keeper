# Play Keeper v1.8.5 — 完整起始阶升阶轮次

## 行为修正

- 达到中止阶并存入成品后，新主宠改为选择“目标起始阶”，不再使用“中止阶−1”。
- 例如设置8→10：每轮依次执行8+8→9、9+9→10，随后从牧场选择新的8阶宠物作为主战。
- 新主宠和副宠继续严格按CC从低到高选择；不优先选择Lv40。若最低CC候选未满40级，仍按原流程补级。
- 升阶模式的“最多周期”改为完整交接轮数，一轮指从目标起始阶升到中止阶并完成换宠、存放成品。

## 时间优化

- 存放成品后不再重复进入宠物资料执行第二次主战核验；此前已经完成主战身份核验，存放事务仍会验证携带数、牧场数和成品行。
- 已在牧场页面时复用当前页面，仅重新扫描列表，不再重复执行牧场导航和等待。
- 保留取出、副宠身份、主战确认、主战身份和成品存放等关键验证。

## 统计

- 新增“完整升阶轮次：启动/完成”。
- 结束原因显示本次实际完成的升阶交接次数。
