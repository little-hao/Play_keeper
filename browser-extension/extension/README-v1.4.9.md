# Play Keeper v1.4.9 — 多周期补级与快速合成重试

## 修复内容

- 背包只滚动真实物品列表 `.msg-box .item-box`；排除聊天区、物品行和外围滚动节点。
- 第二个及后续周期开始前重新确认锁定主宠等级；合成后的新主宠若为 Lv1，会先自动补到 Lv40。
- 牧场页面短暂显示 `当前携带宠物数量 0/3` 时继续等待，至少读到一只携带宠物才进入取宠流程。
- 同一副宠合成失败后的自动重试沿用本轮背包快照，不重复扫描背包。
- 失败冷却和页面恢复只执行一次；后续尝试复用已恢复的合成页并重新核验选择。

## 日志结论

- 第一份诊断的第一周期完整成功；第二周期取出副宠后发现合成产生的新主宠为 Lv1，但循环没有再次执行主宠补级。
- 第二份诊断中第一次合成失败后页面已完成 12 秒冷却和选择恢复，但自动循环又等待 15 秒并重新扫描背包，产生不必要延迟。
- 第二周期进入牧场后在异步加载阶段读取到 `0/3`，因此错误暂停；实际页面随后恢复为 `1/3`。

## 安装

1. 解压 ZIP。
2. 在 `chrome://extensions/` 开启开发者模式。
3. 加载解压根目录，根目录直接包含 `manifest.json`。
4. 刷新游戏页面，重新记录背包、牧场并锁定主宠。

保留 v1.4.8 的强化丹 A→B 回退、进化成功消息和进化次数延迟核验。
