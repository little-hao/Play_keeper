# Play Keeper v1.4.11 — 实时经验组合重算

## 日志结论

- 牧场宠物从 Lv1 使用 500W 经验月饼升到 Lv39 后，v1.4.10 又把该等级的保守上限 80.467W 当作全新目标。
- 后续每使用一次中/小秘籍，目标仍被重置为 80.467W，已消耗经验没有从剩余预算扣除，因此最终错误提示“库存最多 80W，需要至少 80.5W”。
- 本地规划器只在整只宠物完成后写回背包快照；中途停止时仍显示旧的 `500W×1 + 小秘籍×13` 组合。

## v1.4.11 修复

- 每只牧场宠物建立一次经验预算；使用 500W 后直接从 563.3W 中扣除，剩余约 63.3W，不再按 Lv39 重新增加到 80.467W。
- 每次验证道具消耗后，立即扣减本宠物剩余预算，并使用实时库存重新选择下一步组合。
- 每次消耗后立即把库存写回神宠规划器，自动规划结果同步更新；发生中断时也不会继续显示旧库存组合。
- 剩余量不足一个最小经验道具时，只允许使用当前等级安全范围内的最小道具补足，不会退回 200W/500W 大道具。
- 达到预算但页面等级仍未刷新时，先关闭升级弹窗并等待牧场列表更新，再决定是否需要最小补充道具。
- 自动循环中强化丹 A/B 均不足时，停止本轮剩余进化次数并直接进入合成；单次“进化一次”仍按原安全规则停止。

## 使用方式

自动循环前仍应依次锁定主宠、记录背包、记录牧场，并建议先执行“牧场副宠补级”。运行期间可直接观察“自动规划结果”，经验组合会随已验证库存实时变化。
