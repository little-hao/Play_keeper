# Play Keeper v1.8.7 — 设备授权信息扩展

## 插件提交信息

- 用户自定义设备名称；
- 可选设备备注；
- 操作系统名称与可读取的系统版本；
- 浏览器名称与版本；
- 插件版本；
- CPU 架构、位数及浏览器允许读取的设备型号。

IP 地址不由插件查询第三方服务，而是由授权服务器从 HTTPS 请求来源记录。首次激活时间、最后活动时间和停用状态同样由服务器维护。

Chrome 扩展没有可信接口读取 Windows 用户名、主板序列号或硬盘序列号，本版不会伪造或绕过系统权限采集这些信息。

## 服务器兼容

服务器会自动补齐旧设备记录的新字段。旧插件续签时不会删除已有设备名称和备注。被所有者停用的设备无法激活或续签；停用设备不占用活动设备数量。
