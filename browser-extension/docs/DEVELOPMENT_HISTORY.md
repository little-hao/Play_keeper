# 浏览器插件开发记录

## 项目目标

浏览器插件最初用于读取真实 DOM 并安全执行一次进化或一次合成，之后逐步扩展为完整的神宠规划器和可恢复自动循环。所有高风险操作均要求页面状态可验证；找不到唯一目标、身份冲突或结果无法确认时暂停并保留诊断。

## 主要阶段

### v1.2.x：真实 DOM 单次事务

- 保留 v1.2.5 累计经验修复。
- 进化一次：仅对已确认主宠执行，要求 Lv40 且进化次数小于 10；强化丹 A 优先、B 兜底；验证进化次数增加。
- 合成一次：精确记录主副宠，选择守护与辅助材料；默认天神之石和三星成长魂石。
- 增加事务诊断导出，避免无法验证时继续消耗资源。

### v1.3.x：补级、断点与自动循环

- 增加牧场取宠、Lv1→Lv40 经验规划、背包滚动和属性页读取。
- 处理公式神宠与满神/残神模式的阶数差异。
- 自动循环按检查点恢复，不在中断后盲目重头执行。
- 记录用户接管动作、主战切换、宠物身份变化和页面导航失败。

### v1.4.x：牧场预补级与流程稳定性

- 循环前可按阶数与低 CC 优先，在牧场将副宠预先补到 Lv40。
- 绑定与非绑定同名经验道具都可使用，优先绑定资源。
- 合成失败后等待页面稳定，再重新选择主副宠和材料。
- 进化材料不足时跳过进化并进入合成阶段。
- 合并规划器和自动捕捉入口，增加可移动运行提示与周期统计。

### v1.5.0：生产许可证与运行统计

- 授权服务器签发短期 P-256 签名令牌，插件只保存公钥。
- 绑定安装实例并提供有限离线期；服务器私钥不进入用户插件包。
- 无论正常结束或暂停，都统计补级数量、合成成功/失败次数和关键动作。

### v1.5.1：HTTP 页面许可证修复

- 实际 Chrome 错误为 `crypto.subtle.importKey` 未定义。
- 原因是游戏运行于 HTTP 页面，内容脚本所在上下文不能可靠使用 Web Crypto。
- 授权请求与 P-256 签名验证迁移到扩展后台安全上下文。
- 生产服务器地址、公钥、72 小时令牌和设备限制保持不变。

### v1.5.2：关卡 BOSS 刷新与 A/B 对照

- 新增"纯自动战斗"和"普通怪逃跑，仅战 BOSS"两种可比较模式。
- 使用敌方状态栏的真实 DOM 文本匹配可配置 BOSS 名称，不依赖固定坐标或图像颜色。
- 逃跑后必须确认副本"战斗"入口重新出现才进入下一轮，防止倒计时和异步页面造成连续误点。
- 记录普通怪跳过数、BOSS 遇到/完成数和运行时间，用等时长数据选择最优模式。

## 当前安全边界

- 自动循环运行前必须锁定主宠，并记录背包和牧场。
- 主副宠均需达到 Lv40 才能进入合成。
- 单次进化始终作用于锁定公式主宠，不给副宠使用进化材料。
- 页面加载、身份、资源或结果任一无法验证时暂停。
- 自动化不会代替用户保管激活码、服务器私钥和账号凭据。

## 后续建议

- 把页面导航抽象为带超时、稳定性检测和截图/DOM 证据的统一状态机。
- 为牧场、背包、宠物神殿分别保存结构化快照，减少重复扫描。
- 将诊断日志字段版本化，便于跨 Windows、Mac 和未来 Android 辅助端比较。
- 发布前使用脱敏样本做两周期回归，同时保留单次事务作为最小故障定位入口。
